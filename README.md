# avito_bot_detection
## Инструкция по запуску кода
Версия: Python 3.14.3 <br>
В терминале перейти в папку с проектом <br>
Загрузить библиотеки из файла requirements.txt с помощью команды. <br>
```bash
pip install -r requirements.txt 
```
Открыть файл main.ipynb. <br>
Запустить выполнение всех ячеек
